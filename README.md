# ძირკვა (dzirkva)

ქართული საძიებო სისტემა. აჩვენებს მხოლოდ ქართულენოვან გვერდებს და უპირატესობას ადამიანის დაწერილ ტექსტს ანიჭებს:
ბლოგებს, სამეცნიერო ნაშრომებს, ვიკიპედიის წყაროებს, დახურული საიტების ძველ ასლებს.

ძიებაში ენის დიდი მოდელი (LLM) არ მონაწილეობს. მუშაობს მხოლოდ კოდი და ერთი ლოკალური მოდელი, BGE-M3.

საიტი: https://dzirkva.ge

## როგორ ეძებს

1. ასწორებს შეკითხვას: ლათინურ ასოებს ქართულად გადაიყვანს (`kartuli` → `ქართული`), ასწორებს მართლწერას და
   სიტყვებს ლექსიკონის ფორმამდე დაიყვანს (`morph.py` და ka-lemma-ს ცხრილი `data/families.db`).
2. ერთდროულად ეძებს Brave-ში (ერთი ფასიანი მოთხოვნა ერთ ძიებაზე) და საკუთარ ინდექსებში.
3. შედეგებს ალაგებს Brave-ში დაკავებული ადგილის, აზრობრივი სიახლოვის (BGE-M3), წყაროს სანდოობისა და შეკითხვის
   სიტყვების დაფარვის მიხედვით. ყოველი შედეგის ქვეშ ჩანს, რატომ მოხვდა ამ ადგილას.

კოდი: `src/dzirkva/search.py`. ტერმინალიდან: `uv run python -m dzirkva.search ქართული ანბანი`.

## ინდექსები

ყველა ფაილი `data/` საქაღალდეშია და git-ში არ ინახება.

| ფაილი | შიგთავსი |
|---|---|
| `wiki.db`, `wikisource.db` | ქართული ვიკიპედია და ვიკიწყარო |
| `crawl.db` | ჩვენ მიერ შეგროვებული გვერდები: სანდო და იშვიათი ქართული საიტები |
| `passages.db` | დაახლოებით 870 ათასი აბზაცი BGE-M3 ვექტორებით (ვიკიპედია, ნაშრომები, ივერიელი) |
| `papers.db`, `iverieli.db` | სამეცნიერო ნაშრომები (OAI-PMH) და ეროვნული ბიბლიოთეკის კატალოგი |
| `archive.db` | დახურული ქართული საიტების ასლები Internet Archive-დან |
| `families.db` | 1,65 მილიონი სიტყვაფორმა და მათი ლექსიკონის ფორმა (ka-lemma პროექტიდან) |
| `dictionary.db` | ვიქსიკონის განმარტებები |

სანდო საიტების სია: `config/sources.yaml`.

## გაშვება

საჭიროა Python 3.12 და [uv](https://docs.astral.sh/uv/).

```bash
uv sync
uv run python -m dzirkva.web
```

გვერდი იხსნება მისამართზე http://127.0.0.1:8000. `.env` ფაილში უნდა ეწეროს `BRAVE_API_KEY` და `SEARXNG_SECRET`
(ნებისმიერი გრძელი სტრიქონი; მისით ვაწერთ ხელს `/go` ბმულებს). პირველი გაშვებისას BGE-M3 დაახლოებით 2 GB-ს
ჩამოტვირთავს.

`.env` ფაილის სხვა ცვლადები:

| ცვლადი | ნაგულისხმევი | დანიშნულება |
|---|---|---|
| `BRAVE_DAILY_LIMIT`, `BRAVE_MONTHLY_LIMIT` | 20, 300 | Brave-ის მოთხოვნების ლიმიტი; `0` გამორთავს Brave-ს |
| `MAX_SEARCHES` | 3 | რამდენი ძიება შეიძლება მიმდინარეობდეს ერთდროულად |
| `MEANING_WEB` | 1 | `0`: ნელ პროცესორზე შედეგების ახალი ვექტორები არ გამოითვლება |
| `SEARXNG` | 0 | `1`: Yandex-ისა და Yahoo-ს ჩართვა SearXNG-ის გავლით |
| `STATS_KEY` | | `/stats` გვერდის გახსნა სხვა კომპიუტერიდან |

## სერვერი

ძირკვა სახლის სერვერზე მუშაობს (Ubuntu, 7 GB ოპერატიული მეხსიერება, GPU-ს გარეშე) Cloudflare Tunnel-ის
გავლით. systemd-ის ფაილები `config/systemd/` საქაღალდეშია:

- `dzirkva-web`: საძიებო გვერდი;
- `dzirkva-crawl`: გვერდების შემგროვებელი. მუდმივად და ნელა მუშაობს (პროცესორის ერთი ბირთვის მეოთხედი,
  1,2 GB მეხსიერება) და ახალ გვერდებს თავად ამატებს;
- `searxng`: გამორთულია.

კოდის განახლება: `git ls-files -z | rsync -t --files-from=- --from0 . rexvopc:dzirkva/`, შემდეგ `dzirkva-web`
სერვისის გადატვირთვა.

## მონაცემების აგება

ყოველი სკრიპტის დასაწყისში წერია, რა სჭირდება და რამდენ ხანს მუშაობს. თანმიმდევრობა:

1. ენა და ვიკიპედია: `scripts/build_words.py`, `build_lexicon.py`, `build_wiki_index.py`, `build_dictionary.py`,
   `build_titles.py`, `build_vocab.py`.
2. საიტები: `scripts/build_sites.py`, `cc_hosts.py`, `crawl_sites.py`, `score_small_web.py`, `feeds.py`,
   `archive_collect.py`.
3. აბზაცების ვექტორები: `scripts/build_passages.py`.

ივერიელისა და სამეცნიერო ნაშრომების შემგროვებელი სკრიპტები `scripts/archive/` საქაღალდეშია. მათ აღარ ვუშვებთ,
მაგრამ უკვე შეგროვებული მონაცემები ძიებაში გამოიყენება.

## კონფიდენციალურობა

IP მისამართს არ ვინახავთ. ერთი ვიზიტის ნაბიჯებს აკავშირებს შემთხვევითი ქუქი-ფაილი, რომელიც 30 წუთში იშლება;
Do Not Track-ის ან GPC-ის ჩართვისას ქუქი-ფაილი არ იქმნება. ჩანაწერები (`data/telemetry.db`) 180 დღის შემდეგ
იშლება.
